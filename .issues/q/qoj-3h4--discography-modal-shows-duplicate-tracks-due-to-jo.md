The ArtistLocalTracks SQL query joins files to albums on (artist_id, title_norm), but multiple albums can share the same title_norm (e.g. 'Jagged Little Pill', 'Jagged Little Pill (acoustic)', 'Jagged Little Pill (Original Broadway Cast Recording)' all normalize to 'jagged little pill'). This causes each track to appear 2-3x in the discography modal.

Fix: use a subquery to pick one release_date per (artist_id, title_norm) group.

## Summary of Changes

The `ArtistLocalTracks` query joined `files` to `albums` on `(artist_id, title_norm)`, but multiple albums can share the same `title_norm` (e.g. "Jagged Little Pill" and "Jagged Little Pill (acoustic)"), causing each track to appear multiple times in the discography modal.

Fixed by replacing the direct `LEFT JOIN albums` with a subquery that groups by `(artist_id, title_norm)` and picks `MIN(release_date)`, ensuring exactly one row per normalized album title.
