When filtering the artist list by release recency using number key shortcuts (e.g. pressing 1 for last 1 year), the TUI shows '0 artists (last 1 year)' and 'Showing artists with releases in the last 1 year' but no artists are listed, even though there should be matching artists.



## Root Cause

The `ArtistSummaries` SQL query read `latest_date` from the `artists` table (`a.latest_date`), but the sync flow only calls `UpdateArtistMeta` which sets `mbid` and `last_checked_at` — it never populates `latest_date`. All 812 synced artists had empty `latest_date`, so the year filter always found 0 matches.

## Fix

Changed the `ArtistSummaries` query to derive `latest_date` from `MAX(albums.release_date)` via a new `latest_release_date` CTE, instead of relying on the never-populated `artists.latest_date` column.

- `internal/db/db_test.go`: Added `TestArtistSummaries_LatestDateFromAlbums` regression test
